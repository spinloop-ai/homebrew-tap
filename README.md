# spinloop-ai/homebrew-tap

The Homebrew tap for [spinloop-ai/spinloop](https://github.com/spinloop-ai/spinloop) — configure opencode provider catalogues.

## Install

```sh
brew trust --formula spinloop-ai/tap/spinloop
brew install spinloop-ai/tap/spinloop
```

That's it. macOS and Linux, Intel and Apple Silicon.

## Upgrade

```sh
brew update && brew upgrade spinloop
```

New releases land here automatically, usually within a minute of the upstream tag.

## Issues, ideas, PRs

This repo only stores the generated formula — it isn't where the code lives. Please file bugs and feature requests against the upstream project:

- **spinloop** → [spinloop-ai/spinloop](https://github.com/spinloop-ai/spinloop)

## A note for the curious

The formula here is regenerated by [GoReleaser](https://goreleaser.com/) on every upstream release. Hand-edits will be overwritten the next time a release ships, so please don't.
